**Sales Store** is a retail analytics project that explores the relationships between products, regions, customers, discounts, and profitability.  
Using **SQL · Python · Excel · Power Query · DAX · Power BI**, we built an interactive dashboard with KPIs, sales insights, segmentation, and actionable recommendations.

---

## 📌 Project Description

This project aims to transform raw sales data into clear business insights that help decision-makers understand:

- Overall sales performance and trends over time  
- Most profitable products, categories, and regions  
- Impact of discounts on net profit  
- Customer behavior and segmentation  
- Key Performance Indicators (Sales · Profit · Quantity · Margin)

The final deliverable is an interactive **Power BI dashboard** that allows filtering by region, category, segment, and time period.

---

## 🔄 Project Flow

```text
1. Data Collection          →  Gathering raw sales data (Excel / CSV)
2. Data Cleaning            →  Cleaning data using Python + Excel + Power Query
3. Data Storage & Querying  →  Loading cleaned data into SQL for analysis
4. Exploratory Analysis     →  Exploratory analysis using Python + SQL
5. KPI Modeling             →  Creating DAX measures in Power BI
6. Dashboard Development    →  Building interactive visualizations
7. Insights & Presentation  →  Extracting insights and delivering recommendations
```
